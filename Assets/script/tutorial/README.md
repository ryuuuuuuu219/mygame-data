# Tutorial Scripts

チュートリアル専用のスクリプト置き場。

原則:

- M00 / preM00 だけで使う進行管理、表示、スポーン、入力確認はここに置く。
- 本編や他ミッションへの流用を明示的に考慮したものだけ、既存の `mission` 配下や共通側へ置く。
- 流用するか迷うものは、まずここに置いてチュートリアル専用として閉じる。

ここに置く想定:

- 入力確認シーン制御
- M00 チュートリアル進行管理
- チュートリアルHUD文章表示
- 飛行中リマインドHUD
- M00専用スポナー
- M00専用クリア条件

共通化を検討する想定:

- HP と撃破スコアの分離
- 引力場アドオン
- 曳航バルーン / 阻塞気球
- UAV 発着場の補充ロジック

共通化する場合も、最初にこのフォルダで試作し、流用範囲が決まってから移動する。
