01-01.JSON形式仕様決め

## 目的

兵装選択システムで保存する、ドロップ兵装1件分のJSON形式を決める。

保存するのは「強化ポイントの注入量」を中心にする。実数値、前後値、表示文言は、現在のステータス定義から計算して表示する。

## 保存場所

`Application.persistentDataPath` 配下に保存する。

当面は、兵装1件につき1JSONファイルとする。

保存先例:

```text
Application.persistentDataPath/
  weapon_storage/
    MSL-000001.json
    GUN-000001.json
    UGB-000001.json
```

## ファイル単位

1ファイル = 1兵装。

一覧表示時は `weapon_storage` 配下のJSONを読み込み、`discarded == false` のものだけ候補に出す。

読み込みに失敗したファイルはスキップし、ゲームを止めない。

## JSON形式

```json
{
  "version": 1,
  "instanceId": "MSL-000001",
  "weaponTypeId": 1,
  "weaponTypeName": "StandardMissile",
  "serialInType": 1,
  "displayName": "MSL lv.30 #0001",
  "level": 30,
  "sourceStage": "M01",
  "sourceStageIndex": 1,
  "sourceScore": 28500,
  "createdAt": "2026-05-13T12:00:00+09:00",
  "equipped": false,
  "discarded": false,
  "upgradePoints": [5, 6, 0, 3, 1, 0, 2, 4, 0, 5, 4, 0]
}
```

## フィールド

- `version`
  - 保存形式のバージョン。
  - 初期値は `1`。
- `instanceId`
  - 兵装個体ID。
  - 例: `MSL-000001`。
- `weaponTypeId`
  - 兵装種別ID。
  - コード上の分岐に使う。
- `weaponTypeName`
  - 人間が読める種別名。
  - デバッグと表示補助用。
- `serialInType`
  - 種別ごとの通し番号。
  - 表示名やID採番に使う。
- `displayName`
  - UI表示用の名前。
  - 未設定なら読み込み時に `weaponType + lv + serial` から作る。
- `level`
  - 注入された強化ポイント合計。
  - 原則 `upgradePoints` の合計と一致させる。
- `sourceStage`
  - 獲得ステージ名。
  - 例: `M01`。
- `sourceStageIndex`
  - 獲得ステージ番号。
  - `selectedstage + 1` を想定。
- `sourceScore`
  - ドロップ生成に使った最終スコア。
- `createdAt`
  - 生成日時。
- `equipped`
  - 現在装備中なら `true`。
- `discarded`
  - 破棄済み、または一覧非表示なら `true`。
- `upgradePoints`
  - 各ステータスへの注入ポイント配列。
  - 配列順は兵装種別ごとに固定する。

## 実数値の計算

保存された `upgradePoints[index]` を、該当ステータスの `range.min` と `range.step` に適用して実数値へ変換する。

```text
value = range.min + upgradePoint * range.step
```

ただし、`step` が負のステータスもあるため、範囲チェックは `Lower` と `Upper` を使う。

```text
value = clamp(value, range.Lower, range.Upper)
```

例:

```text
ミサイル：装填時間
min = 5.0
max = 0.5
step = -0.1
upgradePoint = 5

value = 5.0 + 5 * -0.1 = 4.5
```

## 前後値の計算

UIに出す前後値は、現在の強化Ptから1ポイント下げた値、1ポイント上げた値を表示する。

```text
prev = clamp(range.min + (upgradePoint - 1) * range.step, range.Lower, range.Upper)
next = clamp(range.min + (upgradePoint + 1) * range.step, range.Lower, range.Upper)
```

## レベル

`level` は `upgradePoints` の合計値。

```text
level = sum(upgradePoints)
```

読み込み時に `level` と合計値が違う場合は、合計値を正として扱う。

## ドロップ生成時のポイント配分

- `level` 分のポイントを、対象兵装の `upgradePoints` にランダム配分する。
- 各ステータスは、対応する `range` の上限を超えない。
- `熱源誘導有効化` のような二値ステータスは、0または1に丸める。
- 未実装ステータスは配分対象から外すか、データだけ保存して適用しない。

## 表示形式

一覧:

```text
MSL lv.30 #0001
```

詳細:

```text
MSL     lv.30

        [強化Pt]    [実数値]    [前後値]
初速    +5          125         120/130
威力    +6          80          75/85
最高速  +0          100         -/105

ページ 1/3 [メインパラメータ] </>
```

表示ページ:

- メインパラメータ
- サブパラメータ 差分のみ
- サブパラメータ すべて

## 前後値表示

前後値は、現在の強化Ptから1ポイント下げた値、1ポイント上げた値を表示する。

表示順は常に `1Pt下げた値 / 1Pt上げた値` とする。

ただし、clamp後の値が現在値と同じになる場合、その側は `-` と表示する。

例:

- 通常: `120/130`
- 下限: `-/105`
- 上限: `190/-`
- 変化なし: `-/-`
