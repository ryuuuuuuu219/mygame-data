# 整理後ロードマップ

## 1. コアシステム

最優先は、ステータスポイント手動振り分けではなく、固定性能の兵装を選ぶ方式へ移行すること。

狙いは、数値を細かく調整するゲームではなく、プレイヤーが「今回の戦い方」を選ぶゲームにすること。

## 2. 戦闘の手触り

機銃と爆弾を先に直す。

- 機銃は当てにくさが爽快感を削っている。
- 爆弾はテレイン接触で炸裂させ、地上攻撃として自然にする。

## 3. ステージと空間

地形の平坦さ、狭さ、空の安っぽさを改善する。

地形自動生成スクリプトを流用できるため、まずは起伏と広さを足して、空戦の高度差と進入ルートに意味を持たせる。

## 4. 企画補助

兵装案、ステージ案、ストーリー導入の是非を別タスクとして整理する。

## 5. 低優先度

ラミエルもどきは現時点では後回し。
