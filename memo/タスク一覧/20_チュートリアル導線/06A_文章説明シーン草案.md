# 文章説明シーン草案

M00に入る前、またはM00中断なしで読ませたい説明を置く。
M00本編では長文を出さず、ワールド内看板とHUDリマインドは短く保つ。

## 説明する項目

```text
基本操作:
ピッチ、ロール、ヨー、加減速、機動制限解除。

目標捕捉:
レーダーの赤い点、ミッション目標、画面端の矢印、緑枠、赤枠。

ターゲットロケーター:
視野外ターゲットの方向表示。
緑の円を画面上へ持っていくロール操作。

HUD / UI:
TGT、HP、Next、Arry。
機首マーカー、進行方向マーカー、横滑り。
Warning、missile alert。

ミサイル:
赤枠ロックオン後に発射。
ロックオンなしでは誘導しない。
撃てない理由: 未ロック、距離過大、再装填、弾切れ。

機銃:
近距離の敵に有効。
照準マーカーを敵に重ねる。
機銃補助標的で最初の命中体験を作る。

兵装切替:
□で兵装を切り替える。
ミサイル、マルチロック、爆弾の違い。

マルチロック:
複数UAVを視界に入れてロック数を増やす。
○で一斉発射する。
```

## 文体方針

- 1文を短くする。
- 操作名と目的を同時に書く。
- 失敗時は責めない表現にする。
- M00側の看板は要約だけにする。

## M00へ渡す要約

```text
目標捕捉:
レーダーの赤い点がミッション目標です。
画面端の矢印を追って、目標を視界に入れてください。

ターゲットロケーター:
視野外の追跡目標は、画面端の緑円で方向を示します。
円が上に来るようにロールして旋回してください。

HUD / UI:
緑枠は追跡対象、赤枠はロックオン完了です。
TGT / HP / Next / Arry と機首・進行方向マーカーを確認してください。

ミサイル / 兵装切替:
赤枠になったら○でミサイルを発射できます。
□で兵装を切り替え、再装填と弾数も確認してください。
```
