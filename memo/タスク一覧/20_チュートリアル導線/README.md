# チュートリアル導線タスク

フライトシューティング初心者向けの導線を追加するための設計メモ群。

原本:

- `memo/原本/◇◇チュートリアル構成.txt`

目的:

- 操作を知らない状態でも、最初の実戦へ入れるようにする。
- HUD、ロックオン、兵装切替、機銃、マルチロックの意味を段階的に理解できるようにする。
- 実装前に、チュートリアル専用要素と本編にも流用できる要素を分ける。

## 実装配置方針

チュートリアル専用のスクリプトは `Assets/script/tutorial` に置く。

ここで流用を明示的に考慮したもの、または本編側への転用を検討しうるもの以外は、既存の `Assets/script/mission` へ混ぜない。

まず `Assets/script/tutorial` に置く想定:

- `preM00` 入力確認
- `M00` 進行管理
- チュートリアルHUD表示
- 飛行中リマインドHUD
- M00専用スポーン制御
- M00専用クリア条件

共通化を検討しうるもの:

- HP と撃破スコアの分離
- 引力場アドオン
- 曳航バルーン / 阻塞気球
- UAV 発着場の補充ロジック

流用するか迷うものは、最初はチュートリアル専用として `Assets/script/tutorial` に閉じる。

## タスク分割

1. `00_前提_HPとスコア分離.md`
   - チュートリアル用の無限湧き UAV をスコア 0 にするための前提。
2. `01_preM00_入力確認シーン.md`
   - 主要入力を一度ずつ確認する操作チェック専用シーン。
3. `02_M00_実戦チュートリアルシーン.md`
   - 実戦内でロックオン、ミサイル、機銃、兵装切替を練習するシーン。
4. `03_引力場アドオン.md`
   - 機銃チュートリアル補助と敵デバフ要素を兼ねるアドオン。
5. `04_UAV無限湧き_マルチロック練習.md`
   - マルチロックミサイル練習用の UAV 発着場設定。
6. `05_飛行中リマインドHUD.md`
   - 一定時間使われていない飛行操作を、HUD 中央やや上に表示して促す。
7. `06_表示文章草案.md`
   - ブリーフィング、HUD、ワールド内案内、リマインド用の表示文草案。
8. `07_M00配置と進行フラグ草案.md`
   - M00 の初期配置、練習エリア、敵スポーン条件、未定義フラグの草案。

## 操作説明文

```text
左スティック左右: ロール
左スティック上下: ピッチ
右スティック: 視点移動
R1: 加速
L1: 減速
R2/L2: ヨー
左スティック押し込み + 減速: 機動制限解除
△: 目標切替
○: ミサイル / 選択兵装発射
×: 機銃
□: 兵装切替
```
