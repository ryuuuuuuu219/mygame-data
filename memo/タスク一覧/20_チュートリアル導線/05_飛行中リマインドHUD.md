# 飛行中リマインド HUD

## 目的

飛行中に一定時間使われていない操作を検出し、HUD の画面中央やや上に短いチュートリアルテキストを表示する。

常時説明ではなく、プレイヤーが詰まっていそうな操作だけを提示する。

## 表示位置

- HUD の画面中央やや上。
- ターゲット枠、速度表示、レーダーと重なりにくい位置に置く。
- 画面中央そのものは照準やロックオン対象を邪魔しやすいため、少し上へ逃がす。

## 表示条件

一定時間、その系統の操作が確認できなかった場合に表示する。

例:

- ピッチ操作が一定時間ない。
- ヨー操作が一定時間ない。
- 旋回らしい姿勢変化が一定時間ない。
- バレルロールが一定時間ない。
- 機動制限解除を使った急旋回が一定時間ない。

## 解除条件

候補:

- 対応する入力が検出されたら解除する。
- `transform.forward` が特定の象限へ入ったら、その操作を理解した扱いで解除する。
- 一定時間、期待する姿勢変化を維持できたら解除する。

`transform.forward` を使う場合の考え方:

- ピッチアップ: `transform.forward.y` が一定値以上になる。
- ヨー / 旋回: 水平方向の向きが一定角度以上変化する。
- バレルロール: `transform.up` またはロール角が一定範囲を通過する。
- 急旋回: 機動制限解除中に旋回角速度、または向きの変化量が閾値を超える。

## 優先度

同時に複数の候補が出た場合は、操作負荷が高く、後続の戦闘理解に効くものを優先する。

優先度:

1. 機動制限解除を使った急旋回
2. バレルロール
3. 旋回
4. ヨー
5. ピッチアップ

## テキスト案

```text
急旋回: 左スティック押し込み + 減速しながら旋回
バレルロール: ロールしながら機首を少し上げる
旋回: 左スティック左右で機体を傾け、左スティック上下で曲がる
ヨー: R2 / L2 で機首を左右へ向ける
ピッチアップ: 左スティック下で機首を上げる
```

## 注意点

- 連続表示しすぎると邪魔になるため、表示にはクールタイムを入れる。
- 既に敵をロック中、ミサイル警告中、撃破演出中などは表示を抑制する。
- 解除判定は入力だけでなく、機体姿勢の結果も見ると「押しただけ」を避けられる。
- 初心者向けなので、最初は入力検出ベースで実装し、必要なら `transform.forward` ベースの姿勢判定を追加する。

## 完了条件

- 一定時間使われていない飛行操作だけが表示される。
- 優先度順に 1 件だけ表示される。
- 対応操作を行うと表示が消える。
- 戦闘 HUD や照準の邪魔にならない。
