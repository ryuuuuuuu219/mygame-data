# M00: 実戦チュートリアルシーン

## 目的

実際に飛びながら、HUD、ロックオン、ミサイル、機銃、兵装切替、マルチロックの流れを覚える。

## ブリーフィング

文面は短くする。

```text
チュートリアルです。
表示される案内に従って、操作と兵装の使い方を確認してください。
```

## HUD 表示

操作説明用テキストを HUD に常時オーバーレイする。

表示する内容:

- 基本操作
- 目標切替
- ロックオン条件
- ミサイル発射
- 機銃の使い方
- 兵装切替

## チュートリアル段階

1. 基本飛行
   - 加速、減速、旋回、視点移動を確認する。
2. 目標捕捉
   - レーダーと画面端の目標方向表示を見て標的へ向かう。
3. ミサイル
   - 目標を正面に捉え、赤枠ロックオン後に発射する。
4. 機銃
   - 低速または補助付き標的に接近し、機銃で撃破する。
5. 兵装切替
   - `□` で兵装を切り替え、選択中兵装の違いを確認する。
6. マルチロック
   - 複数 UAV をロックし、同時撃破を狙う。

## ワールド内案内

マルチロックミサイル練習用 UAV 発着場の上空などに、案内テキストを置く案がある。

候補:

- TextMeshPro のワールドテキスト
- テキストを貼った平面
- HUD 側の距離付き案内

## 完了条件

- ミサイルで標的を撃破できる。
- 機銃で標的を撃破できる。
- 兵装切替を一度行う。
- マルチロックで複数 UAV を撃破する。
- すべて達成したらチュートリアルクリアにする。
