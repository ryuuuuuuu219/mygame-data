# M00 配置と進行フラグ草案

## 前提

このメモに出てくるオブジェクト、フラグ、進行管理名はまだ未定義。

実装時に必要になる候補を先に名前付きで整理するための草案とする。

## シーン遷移

流れ:

1. `preM00` で入力確認を行う。
2. 主要入力をすべて確認したら、確認完了扱いにする。
3. 確認完了後、チュートリアル本編の `M00` へ遷移する。

仮フラグ:

- `preM00InputCheckCompleted`
- `tutorialM00Unlocked`
- `tutorialM00Started`

## M00 初期配置

プレイヤー初期位置:

- 原点付近
- `y = 1500`
- 機首方向は `z+` 方向

意図:

- 周囲に障害物や敵圧を置かず、基本飛行操作だけを確認する。
- この周囲を「基本飛行練習エリア」とする。
- エリア外では、常時説明ではなく飛行中リマインド表示へ切り替える。

仮オブジェクト:

- `TutorialFlightArea`
- `TutorialReminderAreaTrigger`
- `TutorialHudGuideController`

仮フラグ:

- `basicFlightAreaActive`
- `basicFlightGuideCompleted`
- `reminderHudEnabled`

## 基本飛行エリア

原点 `y = 1500` 周辺で確認する操作:

- ピッチアップ / ピッチダウン
- ロール
- ヨー
- 加速 / 減速
- 機動制限解除
- バレルロール
- 急旋回

エリア内:

- 操作説明を出しやすくする。
- 操作ごとの確認フラグを立てる。

エリア外:

- 逐次チュートリアル表示を弱める。
- 未確認または未使用の操作だけ、リマインド HUD で出す。

## 誘引アドオン付き敵機

配置:

- `x = 800`
- `z = -750`
- `y` は基本飛行エリアに合わせて調整する。

用途:

- 機銃練習
- ミサイル練習
- 偏差射撃方向へプレイヤーの機首を向けさせる補助

仮オブジェクト:

- `TutorialAttractorEnemy`
- `TutorialAttractorAddon`
- `TutorialGunMissileTarget`

挙動案:

- 敵機本体とは別に、偏差射撃で狙うべき方向を示す実体を曳航する。
- プレイヤー機首、または照準補助を、その曳航実体方向へ弱く誘引する。
- 実体の接続はヒンジコンポーネント、または類似の拘束表現を検討する。

役割:

- 「敵そのもの」ではなく「当てるべき未来位置」を意識させる。
- 最初の機銃命中体験を作る。
- ミサイル練習にも流用する。

仮フラグ:

- `gunTargetSpawned`
- `gunTargetAttractorEnabled`
- `gunTrainingCompleted`
- `missileTrainingCompleted`

## 無限 UAV 発着場

配置:

- `x = -800`
- `z = -750`
- `y` は基本飛行エリアに合わせて調整する。

用途:

- マルチロックミサイル練習

仮オブジェクト:

- `TutorialUavStorageLauncher`
- `TutorialMultiLockTrainingArea`

挙動案:

- UAV を複数機スポーンする。
- 同時撃破できるまで補充を続ける。
- 撃破スコアは 0。
- 既存候補として `Assets/script/mission/Manager/UAVStorageLauncher.cs` を確認する。

仮フラグ:

- `multiLockAreaActive`
- `multiLockTargetsSpawned`
- `multiLockTrainingCompleted`

## 目標切り替え練習

条件:

- プレイヤーの `z < -800`

挙動:

- 自機の 0 時 / 2 時方向に敵機をスポーンする。
- 距離は約 700。
- 追跡対象切り替え、つまり `△` ボタンの練習に使う。

意図:

- 右手側に見える敵機を追跡している状態を作る。
- 正面付近の敵へ追跡対象を切り替える説明につなげる。
- ターゲットロケーターと追跡対象の違いも確認できるようにする。

仮オブジェクト:

- `TutorialTargetSwitchSpawner`
- `TutorialTargetSwitchEnemyA`
- `TutorialTargetSwitchEnemyB`

仮フラグ:

- `targetSwitchTrainingTriggered`
- `targetSwitchEnemiesSpawned`
- `targetSwitchCompleted`

## 座標メモ

```text
Player start:
  position: (0, 1500, 0)
  forward: z+

Gun / missile target:
  position: (800, ?, -750)

Multi-lock UAV launcher:
  position: (-800, ?, -750)

Target switch trigger:
  condition: player.z < -800
  spawn direction: player 0 o'clock / 2 o'clock
  spawn distance: 700
```

## 決定事項

- 目標切り替え練習の条件は `z < -800`。`y < -800` は誤字。
- 基本飛行エリア外への切り替えは、原点から半径 700。高度差は考慮しない。
- 今明示されているもの以外では、練習エリアを切り替えない。
- 遠距離から標的に撃たせる配置も考慮する。
- M00 内の敵はすべて撃破スコア 0 にする。

## 誘引アドオン方針

プレイヤー姿勢へ直接作用する案を優先する。

処理タイミング:

- `LateUpdate`
- 物理演算前の姿勢補助として扱う想定。

導出の考え方:

- `player.transform.up`
- `player.transform.forward`
- `player.transform.position - gameObject.transform.position`

上記から差分のピッチとヨーを導出し、正規化して吸わせる。

目的:

- プレイヤーの機首を、偏差射撃で狙うべき方向へ弱く向ける。
- 機銃チュートリアルでは照準補助として使う。
- 本編ではデバフとして転用できる余地を残す。

注意:

- 直接姿勢を吸わせるため、強度は控えめにする。
- 急に姿勢が変わると操作不能感が出る。
- 最初はチュートリアル専用の弱い補助から調整する。

## 曳航実体 / バルーン方針

曳航実体は移動制御スクリプトを持たせず、ジョイントで動かす。

方針:

- 物理ジョイントで敵機、または誘引アドオン本体へ接続する。
- スクリプトで直接追従させない。
- バルーンとしてプレハブ化する。

仮プレハブ名:

- `TutorialAimBalloon`
- `TowedAimBalloon`
- `BarrageBalloon`

モチーフ:

- 阻塞気球
- 機銃練習用の曳航標的

役割:

- 実体として「狙うべき未来位置」を見せる。
- 誘引アドオンが吸わせる先としても使える。
- 後で本編の妨害オブジェクトや防空ギミックへ転用できる。
