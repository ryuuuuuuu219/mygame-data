# 表示文章草案

チュートリアル実装時に、ブリーフィング、HUD、ワールド内案内、リマインド表示へ流用するための文章草案。

分割後の主な参照先:

- 文章説明シーン用: `06A_文章説明シーン草案.md`
- M00配置/看板表示用: `06B_M00配置表示草案.md`

文体方針:

- 1文を短くする。
- 操作名と目的を同時に書く。
- 画面中央のHUDは長文にしない。
- 最初は命令形でよいが、失敗時は責めない表現にする。

## preM00: 開始文

```text
操作確認を開始します。
表示された操作を一度ずつ入力してください。
確認できた項目には緑色のラインが付きます。
```

## preM00: 完了文

```text
操作確認完了。
次は実際に飛びながら、目標の捕捉と攻撃を確認します。
```

## M00: ブリーフィング文

短い版:

```text
チュートリアルです。
表示される案内に従って、飛行、ロックオン、攻撃を確認してください。
```

少し説明する版:

```text
チュートリアルです。
この空域では、基本操作、目標捕捉、ミサイル、機銃、兵装切替を順番に確認します。
案内表示に従って操作してください。
```

## M00: 開始直後 HUD

```text
まずは機体を動かします。
左スティックで姿勢を変え、R1で加速、L1で減速します。
```

## 基本飛行

ピッチ:

```text
左スティック上下で機首を上げ下げします。
機首を上げると上昇、下げると降下します。
```

ロール:

```text
左スティック左右で機体を傾けます。
傾けた状態で機首を上げると旋回できます。
```

ヨー:

```text
R2 / L2で機首を左右に向けます。
細かい向きの調整に使います。
```

加減速:

```text
R1で加速、L1で減速します。
速度が落ちすぎると曲がりにくくなります。
```

機動制限解除:

```text
左スティック押し込み + 減速で機動制限を解除します。
急旋回できますが、速度低下に注意してください。
```

## 目標捕捉

```text
レーダーの赤い点がミッション目標です。
画面端の矢印を追って、目標を視界に入れてください。
```

```text
緑の枠は敵機の強調表示です。
現在右手に見える敵機を追跡しています。
```

```text
追跡中の敵機に一定距離、約800mまで接近すると、この枠が赤くなります。
```

```text
△ボタンで正面の敵機に追跡対象を切り替えてみてください。
赤い枠になったら、○でミサイルを発射できます。
```

## ターゲットロケーター

```text
追跡中の敵機が視野外に出ると、画面端に伸縮する緑の円が表示されます。
その方向に、現在追跡している敵機がいます。
```

```text
緑の円が画面の真上に来るようにロールしてください。
そのままピッチアップすると、敵機の方向へ旋回できます。
```

```text
慣れてきたら、表示を追うだけでなく、敵機の動きを読んで先回りしてみましょう。
```

## HUD / UI 説明

ターゲット枠:

```text
緑の枠: 敵機の強調表示、または追跡中の敵機です。
赤の枠: ロックオン完了です。ミサイルを誘導できます。
×印の枠: ECMなどの影響でロックオンが妨害されています。
```

ターゲットラベル:

```text
TGT: ミッション目標です。
HP: 敵機の残り耐久値です。
Next: 次に追跡対象へ切り替わる候補です。
Arry: 味方機です。
```

機首 / 進行方向:

```text
中央付近の機首マーカーは、機体が向いている方向です。
進行方向マーカーは、現在の速度ベクトルです。
機首と進行方向がずれている時は、機体が横滑りしています。
```

機銃リード:

```text
機銃用の照準マーカーは、弾が届く頃の敵位置を予測した目安です。
近距離でこのマーカーへ敵を重ねると、機銃を当てやすくなります。
```

爆弾 / CCIP:

```text
爆弾選択中は、落下予測ラインが表示されます。
ラインの先が目標付近を通るように機体を合わせてから投下してください。
```

警告表示:

```text
Warning: 敵に狙われています。
missile alert: ミサイルが接近しています。回避行動を取ってください。
```

## ミサイル

```text
目標を正面に捉えてください。
赤いロックオン枠が出たら、○でミサイルを発射します。
```

```text
ロックオンしていないミサイルは誘導しません。
赤い枠を確認してから撃ちましょう。
```

撃てない理由:

```text
ロックオンが必要です。
目標を正面に入れて、赤い枠になるまで待ってください。
```

```text
距離が遠すぎます。
目標へ接近してください。
```

```text
再装填中です。
少し待ってからもう一度発射してください。
```

```text
弾切れです。
別の兵装に切り替えてください。
```

## 機銃

```text
×を押している間、機銃を発射します。
近距離の敵には機銃が有効です。
```

```text
照準マーカーを敵に重ねてください。
距離が近いほど当てやすくなります。
```

機銃補助あり:

```text
この標的は照準補助が働きます。
機首を標的へ向け、機銃で撃破してください。
```

## 兵装切替

```text
□で兵装を切り替えます。
ミサイル、マルチロック、爆弾を状況に応じて使い分けます。
```

```text
選択中の兵装が変わりました。
次はこの兵装で目標を攻撃してください。
```

## マルチロック

```text
マルチロック兵装に切り替えてください。
複数の目標を同時にロックできます。
```

```text
複数のUAVを視界に入れてください。
ロック数が増えたら、○で一斉発射します。
```

```text
UAVは補充されます。
同時撃破できるまで、ロックと発射を練習してください。
```

成功:

```text
同時撃破成功。
マルチロックの確認が完了しました。
```

## ワールド内案内

UAV 発着場:

```text
マルチロックミサイルを試してみましょう。
複数のUAVを視界に入れて、一斉発射できます。
```

機銃練習標的:

```text
GUN TRAINING TARGET
接近して機銃で撃破
```

ミサイル練習標的:

```text
MISSILE LOCK TARGET
赤枠になったら発射
```

## M00: 訓練エリア配置メモ

既存の敵配置はチュートリアル範囲の外側へ退避させる前提。
M00内でプレイヤーが使う訓練空域は、基本操作確認、目標捕捉、ターゲットロケーター、HUD/UI説明、ミサイル/兵装切替、機銃補助標的、UAV発着場を基準に確保する。

現状の配置:

```text
基本操作確認:
中心 (0, 1500, 0)
半径 700

目標捕捉説明エリア:
中心 (0, 1500, 1500)
半径 800
用途: レーダーの赤点、ミッション目標、画面端の矢印、緑枠/赤枠の説明

ターゲットロケーター説明エリア:
中心 (-1500, 1500, 500)
半径 700
用途: 視野外ターゲット、画面端の緑円、ロールして方向を合わせる説明

HUD/UI説明エリア:
中心 (1500, 1500, 900)
半径 650
用途: ターゲット枠、TGT/HP/Next/Arry、機首マーカー、進行方向マーカー、警告表示の説明

ミサイル/兵装切替説明エリア:
中心 (1500, 1500, -1500)
半径 800
用途: 赤枠ロックオン、撃てない理由、再装填、弾切れ、兵装切替、選択中兵装の確認

機銃補助エリア / 誘引付きの標的:
中心 (800, 1500, -750)
半径 900

UAV発着場:
発着場オブジェクト (-800, 240, -750)
範囲中心 (-800, 240, -750)
範囲半径 520
UAV湧き中心 (-800, 1500, -950)
UAV湧き半径 280
```

必要なXZ範囲:

```text
基本操作確認: X -700 ～ 700 / Z -700 ～ 700
目標捕捉説明エリア: X -800 ～ 800 / Z 700 ～ 2300
ターゲットロケーター説明エリア: X -2200 ～ -800 / Z -200 ～ 1200
HUD/UI説明エリア: X 850 ～ 2150 / Z 250 ～ 1550
ミサイル/兵装切替説明エリア: X 700 ～ 2300 / Z -2300 ～ -700
機銃補助エリア: X -100 ～ 1700 / Z -1650 ～ 150
UAV発着場: X -1320 ～ -280 / Z -1270 ～ -230
UAV湧き範囲: X -1080 ～ -520 / Z -1230 ～ -670

合成範囲: X -2200 ～ 2300 / Z -2300 ～ 2300
必要最小サイズ: X幅 4500 / Z幅 4600
中心目安: (50, 0)
```

地形サイズの目安:

```text
最小: 4600 x 4600
余白込み推奨: 6000 x 6000
中心を (50, 0) 付近に置くと、7つの訓練エリアを収めやすい。
既存敵はこの推奨範囲の外側、または高度/距離で明確に離した場所へ退避させる。
```

配置意図:

```text
基本操作確認は原点付近に置き、最初の安全な飛行空域にする。
目標捕捉説明エリアは北側へ置き、開始後に前方へ進むだけでレーダー/矢印の説明へつなげる。
ターゲットロケーター説明エリアは左側へ置き、視界外ターゲットを作って画面端表示を確認しやすくする。
HUD/UI説明エリアは北東側へ置き、目標捕捉後に各UI要素を落ち着いて確認できるようにする。
ミサイル/兵装切替説明エリアは南東側へ置き、誘引付き標的と近いが別の説明範囲として扱う。
誘引付きの標的は南東側へ置き、機銃/ミサイル練習の補助対象にする。
UAV発着場は南西側へ置き、マルチロック練習を他エリアから分離する。
```

追加したほうがよさそうな説明:

```text
HUD/UI説明:
ターゲット枠、TGT、HP、Next、Arry、機首マーカー、進行方向マーカーは、実戦前に一度まとめて見せる。
画面上の情報量が多いため、戦闘中の短いHUD説明だけでは理解が追いつきにくい。

ミサイル/兵装切替説明:
ロックオンできない理由、再装填、弾切れ、兵装切替は、失敗時に混乱しやすい。
機銃補助標的とは別に、ミサイルと兵装切替だけを確認する範囲を置くと流れを作りやすい。

警告表示:
Warning、missile alert は、敵を外側へ退避させる場合でも別途デモ敵や安全な演出で説明したい。
ただし常時敵圧を置くと基本操作練習の邪魔になるため、専用エリアまたは一時イベント扱いにする。
```

```text
急旋回できます。
左スティック押し込み + 減速しながら旋回してください。
```

バレルロール:

```text
バレルロールを試してください。

```

旋回:

```text
旋回してみましょう。
機体を傾けてから、機首を上げます。
```

ヨー:

```text
R2 / L2で機首を左右へ調整できます。
目標を中央へ寄せる時に使います。
```

ピッチアップ:

```text
左スティック下で機首を上げます。
高度を取りたい時に使います。
```
