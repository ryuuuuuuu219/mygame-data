# 表示文章草案

チュートリアル実装時に、ブリーフィング、HUD、ワールド内案内、リマインド表示へ流用するための文章草案。

文体方針:

- 1文を短くする。
- 操作名と目的を同時に書く。
- 画面中央のHUDは長文にしない。
- 最初は命令形でよいが、失敗時は責めない表現にする。

## preM00: 開始文

```text
操作確認を開始します。
表示された操作を一度ずつ入力してください。
確認できた項目には緑色のラインが付きます。
```

## preM00: 完了文

```text
操作確認完了。
次は実際に飛びながら、目標の捕捉と攻撃を確認します。
```

## M00: ブリーフィング文

短い版:

```text
チュートリアルです。
表示される案内に従って、飛行、ロックオン、攻撃を確認してください。
```

少し説明する版:

```text
チュートリアルです。
この空域では、基本操作、目標捕捉、ミサイル、機銃、兵装切替を順番に確認します。
案内表示に従って操作してください。
```

## M00: 開始直後 HUD

```text
まずは機体を動かします。
左スティックで姿勢を変え、R1で加速、L1で減速します。
```

## 基本飛行

ピッチ:

```text
左スティック上下で機首を上げ下げします。
機首を上げると上昇、下げると降下します。
```

ロール:

```text
左スティック左右で機体を傾けます。
傾けた状態で機首を上げると旋回できます。
```

ヨー:

```text
R2 / L2で機首を左右に向けます。
細かい向きの調整に使います。
```

加減速:

```text
R1で加速、L1で減速します。
速度が落ちすぎると曲がりにくくなります。
```

機動制限解除:

```text
左スティック押し込み + 減速で機動制限を解除します。
急旋回できますが、速度低下に注意してください。
```

## 目標捕捉

```text
レーダーの赤い点がミッション目標です。
画面端の矢印を追って、目標を視界に入れてください。
```

```text
緑の枠は敵機の強調表示です。
現在右手に見える敵機を追跡しています。
```

```text
追跡中の敵機に一定距離、約800mまで接近すると、この枠が赤くなります。
```

```text
△ボタンで正面の敵機に追跡対象を切り替えてみてください。
赤い枠になったら、○でミサイルを発射できます。
```

## ターゲットロケーター

```text
追跡中の敵機が視野外に出ると、画面端に伸縮する緑の円が表示されます。
その方向に、現在追跡している敵機がいます。
```

```text
緑の円が画面の真上に来るようにロールしてください。
そのままピッチアップすると、敵機の方向へ旋回できます。
```

```text
慣れてきたら、表示を追うだけでなく、敵機の動きを読んで先回りしてみましょう。
```

## HUD / UI 説明

ターゲット枠:

```text
緑の枠: 敵機の強調表示、または追跡中の敵機です。
赤の枠: ロックオン完了です。ミサイルを誘導できます。
×印の枠: ECMなどの影響でロックオンが妨害されています。
```

ターゲットラベル:

```text
TGT: ミッション目標です。
HP: 敵機の残り耐久値です。
Next: 次に追跡対象へ切り替わる候補です。
Arry: 味方機です。
```

機首 / 進行方向:

```text
中央付近の機首マーカーは、機体が向いている方向です。
進行方向マーカーは、現在の速度ベクトルです。
機首と進行方向がずれている時は、機体が横滑りしています。
```

機銃リード:

```text
機銃用の照準マーカーは、弾が届く頃の敵位置を予測した目安です。
近距離でこのマーカーへ敵を重ねると、機銃を当てやすくなります。
```

爆弾 / CCIP:

```text
爆弾選択中は、落下予測ラインが表示されます。
ラインの先が目標付近を通るように機体を合わせてから投下してください。
```

警告表示:

```text
Warning: 敵に狙われています。
missile alert: ミサイルが接近しています。回避行動を取ってください。
```

## ミサイル

```text
目標を正面に捉えてください。
赤いロックオン枠が出たら、○でミサイルを発射します。
```

```text
ロックオンしていないミサイルは誘導しません。
赤い枠を確認してから撃ちましょう。
```

撃てない理由:

```text
ロックオンが必要です。
目標を正面に入れて、赤い枠になるまで待ってください。
```

```text
距離が遠すぎます。
目標へ接近してください。
```

```text
再装填中です。
少し待ってからもう一度発射してください。
```

```text
弾切れです。
別の兵装に切り替えてください。
```

## 機銃

```text
×を押している間、機銃を発射します。
近距離の敵には機銃が有効です。
```

```text
照準マーカーを敵に重ねてください。
距離が近いほど当てやすくなります。
```

機銃補助あり:

```text
この標的は照準補助が働きます。
機首を標的へ向け、機銃で撃破してください。
```

## 兵装切替

```text
□で兵装を切り替えます。
ミサイル、マルチロック、爆弾を状況に応じて使い分けます。
```

```text
選択中の兵装が変わりました。
次はこの兵装で目標を攻撃してください。
```

## マルチロック

```text
マルチロック兵装に切り替えてください。
複数の目標を同時にロックできます。
```

```text
複数のUAVを視界に入れてください。
ロック数が増えたら、○で一斉発射します。
```

```text
UAVは補充されます。
同時撃破できるまで、ロックと発射を練習してください。
```

成功:

```text
同時撃破成功。
マルチロックの確認が完了しました。
```

## ワールド内案内

UAV 発着場:

```text
MULTI LOCK TRAINING AREA
複数のUAVをロックして同時撃破
```

機銃練習標的:

```text
GUN TRAINING TARGET
接近して機銃で撃破
```

ミサイル練習標的:

```text
MISSILE LOCK TARGET
赤枠になったら発射
```

## 飛行中リマインド

急旋回:

```text
急旋回できます。
左スティック押し込み + 減速しながら旋回してください。
```

バレルロール:

```text
バレルロールを試してください。
ロールしながら機首を少し上げます。
```

旋回:

```text
旋回してみましょう。
機体を傾けてから、機首を上げます。
```

ヨー:

```text
R2 / L2で機首を左右へ調整できます。
目標を中央へ寄せる時に使います。
```

ピッチアップ:

```text
左スティック下で機首を上げます。
高度を取りたい時に使います。
```

```text
チュートリアル完了。
基本操作、ロックオン、攻撃、兵装切替を確認しました。
```

```text
次のミッションからは実戦です。
レーダーとHUDを見ながら、ミッション目標を撃破してください。
```
