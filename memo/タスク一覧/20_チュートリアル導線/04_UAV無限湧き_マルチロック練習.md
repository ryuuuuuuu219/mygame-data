# UAV 無限湧き: マルチロック練習

## 目的

マルチロックミサイルのロック、発射、同時撃破を練習できる標的群を用意する。
ただし、M00 のクリア条件には絡めない。

関連候補:

- `Assets/script/mission/Manager/UAVStorageLauncher.cs`

## 基本仕様案

- UAV 発着場に無限湧き用の設定を付ける。
- スポーン済み UAV を 4 枠管理する。
- 4 枠のうち 1 機でも `null`、つまり撃破済みになったら補充タイマーを開始する。
- 3 秒経過で不足分を補充する。
- 同時に倒すまで練習を続けられる。
- チュートリアル用 UAV の撃破スコアは 0 にする。
- UAV はミッションターゲットにしない。
- UAV 発着場上空に案内表示を置き、任意練習として扱う。

## チュートリアル進行

1. プレイヤーを UAV 発着場付近へ誘導する。
2. 複数 UAV を表示する。
3. マルチロック可能な兵装へ切り替えさせる。
4. 複数ロック状態を作らせる。
5. 同時撃破できたら補助メッセージを出す。

案内文:

```text
マルチロックミサイルを試してみましょう。
複数のUAVを視界に入れて、一斉発射できます。
```

## 注意点

- スコア 0 のため、HP と撃破スコアの分離が先に必要。
- 無限湧きが通常ミッションの敵数カウントやクリア条件を壊さないようにする。
- ミッションターゲットにしないことで、クリア判定とは分離する。
- 補充直後にプレイヤーへ衝突しないスポーン位置にする。
- ロックオン練習なので、ECM や高機動回避は入れない。

## 完了条件

- UAV が不足時に自動補充される。
- スコア 0 で撃破できる。
- UAV がミッションターゲットにならない。
- 発着場上空の案内で、マルチロック練習エリアだと分かる。
