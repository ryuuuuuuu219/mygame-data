# M00配置表示草案

文章説明シーンで詳細を読ませる前提。
M00では、各訓練エリアに短い看板を置き、実操作に集中させる。

## 実装済み看板エリア

```text
基本操作確認:
中心 (0, 1500, 0)
半径 700

目標捕捉:
中心 (0, 1500, 1500)
半径 800

ターゲットロケーター:
中心 (-1500, 1500, 500)
半径 700

HUD / UI確認:
中心 (1500, 1500, 900)
半径 650

ミサイル / 兵装切替:
中心 (1500, 1500, -1500)
半径 800

機銃補助エリア / 誘引付きの標的:
中心 (800, 1500, -750)
半径 900

UAV発着場:
発着場オブジェクト (-800, 240, -750)
範囲中心 (-800, 240, -750)
範囲半径 520
UAV湧き中心 (-800, 1500, -950)
UAV湧き半径 280
```

## 必要なXZ範囲

```text
基本操作確認: X -700 ～ 700 / Z -700 ～ 700
目標捕捉: X -800 ～ 800 / Z 700 ～ 2300
ターゲットロケーター: X -2200 ～ -800 / Z -200 ～ 1200
HUD / UI確認: X 850 ～ 2150 / Z 250 ～ 1550
ミサイル / 兵装切替: X 700 ～ 2300 / Z -2300 ～ -700
機銃補助エリア: X -100 ～ 1700 / Z -1650 ～ 150
UAV発着場: X -1320 ～ -280 / Z -1270 ～ -230
UAV湧き範囲: X -1080 ～ -520 / Z -1230 ～ -670

合成範囲: X -2200 ～ 2300 / Z -2300 ～ 2300
必要最小サイズ: X幅 4500 / Z幅 4600
中心目安: (50, 0)
```

## 地形サイズ目安

```text
最小: 4600 x 4600
余白込み推奨: 6000 x 6000
中心を (50, 0) 付近に置くと、7つの訓練エリアを収めやすい。
既存敵はこの推奨範囲の外側、または高度/距離で明確に離した場所へ退避させる。
```

## 配置意図

```text
基本操作確認は原点付近に置き、最初の安全な飛行空域にする。
目標捕捉は北側へ置き、開始後に前方へ進むだけでレーダー/矢印の説明へつなげる。
ターゲットロケーターは左側へ置き、視界外ターゲットを作って画面端表示を確認しやすくする。
HUD / UI確認は北東側へ置き、目標捕捉後に各UI要素を落ち着いて確認できるようにする。
ミサイル / 兵装切替は南東側へ置き、誘引付き標的と近いが別の説明範囲として扱う。
誘引付きの標的は南東側へ置き、機銃/ミサイル練習の補助対象にする。
UAV発着場は南西側へ置き、マルチロック練習を他エリアから分離する。
```
