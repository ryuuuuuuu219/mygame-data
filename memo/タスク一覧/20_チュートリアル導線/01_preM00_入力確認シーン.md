# preM00: 入力確認シーン

## 目的

プレイヤーが主要操作を一度ずつ確認してから、実戦チュートリアルへ進めるようにする。

## 画面構成

- 既存の入力可視化 UI（C:\はこんばっと\Assets\script\mission\Player\InputTextUI.cs） を画面中央に表示する。
- 操作説明テキストを周囲に配置する。
- 入力 UI と説明テキストをラインで結ぶ。
- 対応する入力を検出したら、説明テキストに緑色アンダーラインを引く。

## 確認する入力

- 左スティック左右: ロール
- 左スティック上下: ピッチ
- 右スティック: 視点移動
- `R1`: 加速
- `L1`: 減速
- `R2` / `L2`: ヨー
- 左スティック押し込み + 減速: 機動制限解除
- `△`: 目標切替
- `○`: ミサイル / 選択兵装発射
- `×`: 機銃
- `□`: 兵装切替

## 進行

1. シーン開始時に入力確認 UI を表示する。
2. 各入力を検出するたびに、該当項目を確認済みにする。
3. 全主要入力が確認済みになったら「確認完了」を表示する。
4. 決定入力で `M00` へ進む。

## 完了条件

- 主要入力の確認状態が視覚的に分かる。
- 全入力確認後に M00 へ遷移できる。
- 操作説明が文字だけでなく、入力可視化 UI と対応している。
