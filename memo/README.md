# はこんばっと 開発メモ

このフォルダは、はこんばっとの設計メモ、タスク、操作説明、レベルデザイン資料をまとめる場所です。

## 目下の最大課題

現在の最優先は、`タスク一覧/01_システム/兵装選択システム.md` の兵装選択システムです。

ステータスポイントを手動で細かく振り分ける方式をやめ、ステージクリア後にスコア由来のポイントで兵装・武器ステータスを抽選し、ドロップ品として倉庫に保存、次回出撃前に選択する方式へ移行します。

狙いは、数値調整の管理を減らし、プレイヤーが「今回の戦い方」を選ぶゲームに寄せることです。

## 現在のロードマップ

### 1. コアシステム

- 兵装選択システムを最優先で進める。
- 手動ステータス変更UIを撤去し、兵装倉庫から選ぶUIに置き換える。
- ゲームシーンとリザルトシーンの間、またはリザルト処理内で兵装ドロップ生成を行う。
- JSON形式でドロップ兵装の倉庫を保存する。

### 2. 戦闘の手触り

- プレイヤー機銃の当たり判定を改善する。
- 爆弾を近接信管ではなく、テレインコライダー接触時に炸裂する挙動へ変える。

### 3. ステージと空間

- 地形の広さと起伏を改善する。
- 空と雲を追加し、空戦としての見た目を底上げする。
- 兵装選択の違いが出るステージ構成を考える。

### 4. 企画補助

- 兵装案、ステージ案、ストーリー導入の是非を別タスクとして整理する。

### 5. 低優先度

- ラミエルもどきは現時点では後回し。

## 現在の主な問題

- 成長方式がステータスポイント手動振り分け寄りで、空戦アクションのテンポと噛み合いにくい。
- 地形が平らで狭く、空戦や爆撃の面白さが出にくい。
- 雲がなく、空の見た目がチープに見える。
- プレイヤー機銃の当たり判定が弱く、気持ちよく当てにくい。
- 爆弾が近接信管風の処理で、地面に落として炸裂する納得感が弱い。

## 次に見ること

- 兵装選択システムのデータ形式、ドロップ生成、保存、選択UIを順に実装する。
- 機銃の判定方式を見直す。
- 爆弾のTerrainCollider接触炸裂を実装する。
