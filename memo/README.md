# はこんばっと 開発メモ

このフォルダは、はこんばっとの設計メモ、タスク、操作説明、レベルデザイン資料をまとめる場所です。

## Discord連携で読まれる主要ファイル

GitHub Actions の Discord project summary は、次のファイルを要約材料として読む設定です。

- `memo/README.md`
- `memo/ROADMAP.md`
- `memo/タスク一覧/進捗確認.md`
- `memo/タスク一覧/整理後/ロードマップ.md`

このため、進捗共有に載せたい内容は上記ファイルへ要約し、詳細は各タスクフォルダに置きます。

## フォルダ構成

- `タスク一覧/01_システム/`: 兵装選択、成長方式などゲームの根幹に関わるタスク
- `タスク一覧/02_QoL/`: 操作感、当たり判定、地形、空などプレイ体験改善タスク
- `タスク一覧/03_企画補助/`: 兵装、ステージ、ストーリー導入のアイデア整理
- `タスク一覧/90_低優先度/`: すぐに着手しないが残しておく項目
- `資料/操作説明/`: 操作説明テキストとUI説明画像
- `資料/レベルデザイン/`: レベルデザイン表
- `原本/`: 分割前のメモ原文

## 現在の注意

- `memo/レベルデザイン.xlsx` は別プロセスが使用中のため、原本がルートに残っています。内容は `資料/レベルデザイン/レベルデザイン.xlsx` にコピー済みです。
- `~$レベルデザイン.xlsx` はExcelの一時ファイルなので、管理対象にしません。
