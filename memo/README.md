# はこんばっと 開発メモ

このフォルダは、はこんばっとの設計メモ、タスク、操作説明、レベルデザイン資料をまとめる場所です。

## 現在の状態

2026-05-18時点では、M01地上敵配置そのものより先に、戦闘の土台と演出まわりの実装が進んでいます。

- `SpawnTableManager` は `stage_spawns.json` を読み込み、Wave開始、Waveクリア、ステージクリア、M02手動ステージ分岐を扱う。
- プレイヤー機銃、敵機銃、プレイヤーミサイル、敵ミサイルは TerrainCollider 判定が入り、地形命中時に消滅する。
- 爆弾は前フレーム位置から現在位置までの Terrain Raycast で地形着弾を検出し、着弾地点で爆発する。
- `GeneratedAudioManager` により、全シーン常駐の仮BGM/仮SE、警告ループ、シーン別BGM切替が入っている。
- UI、武器、命中、撃破、Wave開始、Stage Clear など主要イベントから仮SEを鳴らす導線がある。
- タイトル画面は、敵味方プレハブを召喚して戦闘を見せる方向で洗練タスクが追加されている。

## 目下の最大課題

最優先は、仮実装済みの戦闘基盤を実地確認しながら、M01/M02のゲーム体験として見える形にまとめることです。

1. 弾・ミサイル・爆弾の Terrain 判定をM01の地形上で確認する。
2. `stage_spawns.json` と `SpawnTableManager` の現行仕様を崩さず、M01の地上敵・防空網配置へつなげる。
3. 仮BGM/仮SEを維持したまま、本制作音源へ差し替えられる設計にする。
4. タイトル画面で「空戦ゲームであること」が一目で伝わる背景戦闘を作る。

## 現在のロードマップ

### 1. 戦闘基盤の確認と調整

- 機銃・ミサイルの TerrainCollider 命中時消滅を実地確認する。
- 爆弾の地形着弾爆発を確認し、近接信管寄りの挙動が残る場合は整理する。
- プレイヤー機銃の SphereCast 半径、敵弾・敵ミサイルの Raycast 判定、爆弾の着弾位置を調整する。
- 命中、撃破、爆発、警告SEの鳴り方を実プレイで確認する。

### 2. M01 地上敵配置

- M01に地形に沿った地上敵を配置し、航空機中心の敵構成から防空網を含む構成へ切り替える。
- `stage_spawns.json` の新旧形式両対応方針を維持する。
- AA_GUN、SAM、長射程SAM、ミッション目標、非必須防空戦力をJSON上で読み分けられる形にする。
- `SpawnPlacementManager` の地形スナップ・配置補助を使い、固定配置とランダム配置の両方を検討する。

### 3. 音まわり

- `GeneratedAudioManager` の仮BGM/仮SEを、開発中の無音防止とタイミング確認用として維持する。
- 本制作音源は `GeneratedAudioCue` / `GeneratedBgmState` を入口にして、後から `AudioClip` アセット参照へ差し替える。
- シーン別BGM、ミサイル警報、ロック警報、エンジン/風切り音の優先度を整理する。

### 4. タイトル画面

- タイトル背景で敵味方プレハブをいくつか召喚し、空戦・対空戦闘を見せる。
- メニュー操作を邪魔しない範囲で、ゲームの目的と雰囲気が伝わる画面にする。

### 5. コアシステム

- 兵装選択システムは、戦闘基盤とM01配置の確認後に進める。
- 手動ステータス変更UIを撤去し、兵装倉庫から選ぶUIに置き換える。
- ゲームシーンとリザルトシーンの間、またはリザルト処理内で兵装ドロップ生成を行う。
- JSON形式でドロップ兵装の倉庫を保存する。

### 6. 戦闘QoLとステージ

- 地形の広さと起伏を改善する。
- 空と雲を追加し、空戦としての見た目を底上げする。
- 兵装選択の違いが出るステージ構成を考える。

### 90. 低優先度

- ラミエルもどきは現時点では後回し。

### 91. リプレイ

- 敵視点カメラ、スナップショットリプレイ機能は後回し項目として残す。

## 現在の主な問題

- Terrain 判定と爆弾着弾爆発はコード上入っているが、M01地形上での確認と数値調整が必要。
- 地上敵・防空網の実配置がまだゲーム体験としてまとまりきっていない。
- 地形が平らで狭く、空戦や爆撃の面白さが出にくい。
- 雲がなく、空の見た目がチープに見える。
- 本制作音源は未着手で、現在は生成音による仮BGM/仮SE。
- 兵装選択・成長方式は設計メモがあるが、実装優先度は戦闘基盤確認の後。
