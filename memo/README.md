# はこんばっと 開発メモ

このフォルダは、はこんばっとの設計メモ、タスク、操作説明、レベルデザイン資料をまとめる場所です。

## 目下の最大課題

現在の最優先は、`タスク一覧/01_M01地上敵配置/M01地上敵配置.md` の M01 地上敵配置です。

M01 に地形に沿った地上敵を配置し、航空機中心の敵構成から、対空機銃・SAM・防空網を含むミッション構成へ切り替えます。

## 現在のロードマップ

### 1. M01 地上敵配置

- M01 に地形に沿って地上敵を配置し、航空機と置き換える。
- 対空機銃（AA_GUN）をプレハブ化する。
- 対空ミサイル（SAM）をプレハブ化する。
- SAM を防空網として強化し、対象高度に応じて射程が伸びるようにする。

### 2. 弾と地形の判定

- 機銃とミサイル（敵味方両方）に、TerrainCollider への当たり判定と消滅処理を追加する。

### 3. コアシステム

- 兵装選択システムを、M01 地上敵配置と弾 Terrain 判定の後に進める。
- 手動ステータス変更UIを撤去し、兵装倉庫から選ぶUIに置き換える。
- ゲームシーンとリザルトシーンの間、またはリザルト処理内で兵装ドロップ生成を行う。
- JSON形式でドロップ兵装の倉庫を保存する。

### 4. 戦闘の手触り

- プレイヤー機銃の当たり判定を改善する。
- 爆弾を近接信管ではなく、テレインコライダー接触時に炸裂する挙動へ変える。

### 5. ステージと空間

- 地形の広さと起伏を改善する。
- 空と雲を追加し、空戦としての見た目を底上げする。
- 兵装選択の違いが出るステージ構成を考える。

### 6. 企画補助

- 兵装案、ステージ案、ストーリー導入の是非を別タスクとして整理する。

### 90. 低優先度

- ラミエルもどきは現時点では後回し。

### 91. リプレイ

- 敵視点カメラ、スナップショットリプレイ機能を後回し項目として残す。

## 現在の主な問題

- 成長方式がステータスポイント手動振り分け寄りで、空戦アクションのテンポと噛み合いにくい。
- 地形が平らで狭く、空戦や爆撃の面白さが出にくい。
- 雲がなく、空の見た目がチープに見える。
- プレイヤー機銃の当たり判定が弱く、気持ちよく当てにくい。
- 爆弾が近接信管風の処理で、地面に落として炸裂する納得感が弱い。
